# Applications_of_RL
Companion GitHub repository for my master's thesis, Applications of Reinforcement Learning to Conjectures over Large Discrete Spaces.

The ```main.ipynb``` file is a python notebook with commented code of our implementation of the MDPs and of the Sarsa algorithm.

Each folder corresponds to one of our four experiments and contains:
- The ```.py``` script used to run the experiments, with parallelized and optimized code using Numba;
- The results of the experiments for each method in the form of ```.csv``` files;
- A pre-run python notebook with the code used for the plots in Chapter 4.
